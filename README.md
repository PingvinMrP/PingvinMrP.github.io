# Почта для Python

Интерактивный тренажёр по практической работе № 4 «API-запросы из Python. Библиотека requests».

## Как открыть

1. Распакуйте архив.
2. Дважды щёлкните `index.html`. Сайт откроется в браузере, сервер не нужен.
3. Для урока откройте `slides.html` (или кнопку «▶ Презентация» на сайте).

Шрифты подгружаются из Google Fonts. Без интернета сайт тоже работает, просто с системными шрифтами.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Главная страница тренажёра |
| `slides.html` | Презентация для рассказа классу (13 слайдов, заметки докладчика) |
| `css/style.css` | Общий стиль, светлая и тёмная тема |
| `css/slides.css` | Стиль презентации |
| `js/core.js` | Подсветка кода, учебные серверы, живые запросы, очки опыта |
| `js/app.js` | Анимация, разбор адреса, конструктор, 10 заданий, вопросы, шпаргалка |
| `js/games.js` | Игры: «Почтальон», «Какой штамп?», «Найди ошибку» |
| `js/slides.js` | Листание презентации |

## Разделы сайта

- **Анимация** — письмо летит на сервер и обратно, 4 сценария (200, 201, 404, 401).
- **Словарь на пальцах** — 8 терминов через метафору почты и кликабельный разбор URL.
- **Конструктор** — собираете запрос, видите конверт, код на Python и сырой HTTP. Два режима: учебный сервер (без интернета) и настоящий интернет (jsonplaceholder.typicode.com и httpbin.org).
- **10 заданий** — все задания методички с пошаговым разбором кода по строкам.
- **3 игры** — сборка письма под задачу, угадай статус-код на время, найди строку с ошибкой.
- **Контрольные вопросы** с ответами и **шпаргалка** с кнопками «Копировать».
- **Уровни и значки** — прогресс сохраняется в браузере (кнопка с уровнем в шапке).

## Презентация: управление

`←` `→` или пробел — листать (элементы на слайде появляются по очереди), `F` — полный экран, `N` — заметки докладчика. На телефоне — свайп.

## Как выложить в интернет (чтобы у всего класса была ссылка)

- **Netlify Drop**: откройте app.netlify.com/drop и перетащите папку — ссылка появится сразу.
- **GitHub Pages**: загрузите файлы в репозиторий → Settings → Pages → ветка `main`.
