Библиотека requests — это почтальон: носит письма туда и обратно.

HTTP-методы

Что сделать с письмом: четыре штампа

GETполучить
POSTсоздать
PUTзаменить
DELETEудалить

GET читают, POST создают, PUT меняют, DELETE удаляют.

Статус-коды

Штамп на ответе: смотрите на первую цифру

2xx

Успех. 200 OK, 201 Created.

3xx

Переадресация на новый адрес.

4xx

Ошибка клиента: 404 не найдено, 401 нет доступа.

5xx

Ошибка сервера: 500 — сломалось у них.

Формат данных

JSON — это словарь Python в виде текста

Приходит с сервера (JSON):

{
  "id": 1,

  "active": true,
  "phone": null

После response.json() (словарь):

{'id': 1,

user["name"]  # 'Leanne Graham'
Первый запрос

Три строки: подключить, отправить, прочитать

pip install requests          # один раз, в терминале

import requests

response = requests.get("https://jsonplaceholder.typicode.com/users/1")
print(response.status_code)   # 200
print(response.json()["name"])  # Leanne Graham
Что лежит в ответе

response — это конверт с ответом

response.status_code   # штамп: 200, 404, 500…
response.ok            # True, если код меньше 400
response.json()        # содержимое как словарь или список
response.text          # содержимое как простой текст
response.headers       # пометки на конверте ответа
response.url           # по какому адресу ходили
Параметры и заголовки

params уточняют запрос, headers подписывают конверт

# только посты пользователя 1
requests.get(url + "/posts",
             params={"userId": 1})
# → …/posts?userId=1
# пометки на конверте
headers = {
    "User-Agent": "MyPythonApp",
    "Authorization": "Bearer токен",
}
requests.get(url, headers=headers)
Отправка данных

POST и PUT: данные едут во вложении

new_post = {"title": "foo", "body": "bar", "userId": 1}

r = requests.post(url + "/posts", json=new_post)   # создать → 201
r = requests.put(url + "/posts/1", json=new_post)  # заменить → 200
r = requests.delete(url + "/posts/1")              # удалить → 200

# json=  отправляет настоящий JSON  ✓
# data=  отправляет форму, userId станет строкой "1"
Обработка ошибок

Письмо может потеряться — будьте готовы

try:
    r = requests.get(url + "/invalid-url", timeout=5)
    r.raise_for_status()      # 4xx / 5xx → исключение
    print(r.json())
except requests.exceptions.RequestException as e:
    print("Ошибка запроса:", e)

Без raise_for_status() код 404 ошибкой не считается, и except не сработает.
